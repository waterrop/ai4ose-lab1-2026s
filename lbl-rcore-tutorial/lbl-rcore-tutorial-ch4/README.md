## 核心概念

### 虚拟内存

**为什么需要虚拟内存？**

- **隔离保护**：每个进程有自己的地址空间，互不干扰
- **简化编程**：进程可以使用连续的统一地址空间
- **内存复用**：可以运行比物理内存更大的程序

### Sv39 三级页表

RISC-V Sv39 使用 39 位虚拟地址，分为三级页号：

```
虚拟地址（39位）
┌──────────┬──────────┬──────────┬──────────┐
│  VPN[2]  │  VPN[1]  │  VPN[0]  │  Offset  │
└──────────┴──────────┴──────────┴──────────┘
  [27:18]   [17:9]    [8:0]     [11:0]
    ↓         ↓         ↓
  页表级3    页表级2   页表级1    页内偏移
```

### 地址空间布局

```
内核地址空间                 用户地址空间
┌─────────────┐            ┌─────────────┐
│  .text      │            │  未映射      │
│  .rodata    │            ├─────────────┤
│  .data      │            │   用户栈     │
│  (heap)     │            ├─────────────┤
│             │            │   映射区域   │
│  恒等映射   │            │  (ELF加载)   │
├─────────────┤            ├─────────────┤
│  传送门     │◄─────────►│  传送门     │
└─────────────┘            └─────────────┘
```

### 异界传送门（MultislotPortal）

解决跨地址空间切换问题：内核和用户进程使用不同的页表，通过传送门实现切换。
